Política de Privacidad

Última actualización: 28/09/2026

1. Responsable

El responsable de esta aplicación es Alejandro Martinez Lopez. Para cuestiones relacionadas con privacidad puedes contactar en incruisesmartinez@gmail.com.

2. Qué hace la aplicación

Automatización InCruises Alejandro permite al usuario conectar su cuenta de TikTok mediante el sistema de autorización de TikTok y enviar vídeos seleccionados por el propio usuario a TikTok.

3. Datos que puede procesar

Cuando el usuario autoriza la conexión con TikTok, la aplicación puede recibir los datos básicos que TikTok ponga a disposición de la aplicación mediante los permisos autorizados, así como información necesaria para realizar el envío de los vídeos solicitado por el usuario.

4. Finalidad

Los datos se utilizan únicamente para proporcionar las funciones solicitadas por el usuario, gestionar la conexión con TikTok y realizar el flujo de envío de contenido autorizado.

5. Conservación y seguridad

Los datos se conservarán únicamente durante el tiempo necesario para prestar las funciones de la aplicación y cumplir las obligaciones legales aplicables. Se aplicarán medidas razonables de seguridad para proteger la información contra acceso, modificación o divulgación no autorizados.

6. Compartición de datos

No se venden datos personales. La aplicación utiliza los servicios de TikTok cuando el usuario decide conectar su cuenta y enviar contenido. No se compartirán datos con terceros para fines publicitarios propios.

7. Derechos

El usuario puede solicitar información, corrección, eliminación u otras actuaciones respecto de sus datos, cuando proceda conforme a la legislación aplicable, escribiendo a incruisesmartinez@gmail.com.

8. Cambios

Esta política puede actualizarse para reflejar cambios en la aplicación o en las obligaciones legales. La fecha de actualización aparecerá al principio de esta página.

9. Contacto

Para cualquier cuestión sobre privacidad: incruisesmartinez@gmail.com.
